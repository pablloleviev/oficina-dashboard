# 🚗 Sistema de Gestão de Oficina

## 📌 Descrição do Problema

Pequenas oficinas mecânicas frequentemente enfrentam dificuldades para organizar e acompanhar os serviços realizados. A falta de controle pode gerar perda de informações, atrasos e desorganização no fluxo de trabalho.

## 💡 Solução Proposta

Este projeto é uma aplicação web simples que permite o registro, visualização, edição e exclusão de serviços de uma oficina, facilitando o controle e melhorando a organização do dia a dia.

## 🎯 Público-Alvo

- Donos de oficinas mecânicas
- Mecânicos autônomos
- Pequenos empreendedores do setor automotivo

## ⚙️ Funcionalidades

- Cadastro de serviços
- Edição de serviços
- Exclusão de serviços
- Busca por cliente
- Filtro por status (Concluído, Em andamento, Aguardando)
- Dashboard com métricas
- Visualização em tabela

## 🛠️ Tecnologias Utilizadas

- React
- Vite
- JSON Server (API fake)
- ESLint (Linting)
- Vitest (Testes automatizados)
- GitHub Actions (CI)
