# 🛠️ Sistema de Gestão de Oficina

## 📌 Descrição do Projeto
Aplicação web para gerenciamento de serviços em oficinas mecânicas, permitindo controle completo dos atendimentos realizados.

---

## 🚨 Problema Real
Oficinas pequenas frequentemente utilizam papel ou memória para controle de serviços, o que gera:

- perda de dados
- desorganização
- falta de controle financeiro
- dificuldade de acompanhamento

---

## 💡 Solução
O sistema permite:

- cadastrar serviços
- editar e excluir registros
- acompanhar status (Concluído, Em andamento, Aguardando)
- visualizar métricas em dashboard
- filtrar e buscar clientes
- visualizar dados em tabela organizada

---

## 🎯 Público-Alvo
- Oficinas mecânicas pequenas e médias
- Profissionais autônomos

---

## ⚙️ Tecnologias Utilizadas

- React
- JavaScript
- Vite
- JSON Server
- ESLint
